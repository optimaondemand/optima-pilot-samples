A

Reading a limit from a table

From What a Limit Is

The limit limx→a f(x) = L means that f(x) gets as close to L as you like when x is close to a but not equal to a. The value f(a) is never used. To estimate a limit, compute f at values on both sides of a, each closer than the last, and see what both lists head toward.

ExampleEstimate limx→1 x2 − 1x − 1.
  1. At x = 1 the expression is 0 ÷ 0, so it has no value there. Look near 1 instead.
  2. From the left: f(0.9) = 1.9, f(0.99) = 1.99, f(0.999) = 1.999.
  3. From the right: f(1.1) = 2.1, f(1.01) = 2.01, f(1.001) = 2.001.
  4. Both lists head toward 2, so the limit is 2, even though f(1) does not exist.

2Values of f from both sides of 2 head toward 4, and f(2) is undefined. What is limx→2 f(x)?

B

Limit laws and substitution

From The Limit Laws

If limx→a f(x) = F and limx→a g(x) = G, then the limit of a sum, difference, constant multiple, or product is the same combination of F and G. A power or root works the same way, and so does a quotient, provided G is not 0. If an outer function is continuous at the inner limit, you may substitute the inner limit (the composition law). So for a polynomial, the limit as x → a is the value at a. For a fraction of polynomials it is too, as long as the bottom is not 0 at a.

ExampleEvaluate limx→3 x2 + 4x + 1.
  1. The bottom is a polynomial with limit 3 + 1 = 4, which is not 0, so the quotient law applies.
  2. The top is a polynomial, so its limit is 32 + 4 = 13.
  3. The limit is 134.

C

One-sided limits

A new skill, restated in full

The left limit limx→a− f(x) uses only values of x below a. The right limit limx→a+ f(x) uses only values above a. For a function defined in pieces, use the rule that holds on that side. The two-sided limit exists exactly when both one-sided limits exist and are equal. It then equals that common value. The value f(a) plays no part in whether the limit exists.

ExampleFor p(x) = x + 2  when x < 15 − x  when x ≥ 1, decide whether limx→1 p(x) exists.
  1. Left of 1, the rule is x + 2. As x → 1− it heads to 1 + 2 = 3.
  2. Right of 1, the rule is 5 − x. As x → 1+ it heads to 5 − 1 = 4.
  3. The value is p(1) = 4, because x ≥ 1 uses the second rule.
  4. The sides disagree, 3 and 4, so the limit does not exist. Matching the value 4 on one side does not rescue it.

Type negatives with -.

1Let q(x) = 2x − 1  when x < 310 − x  when x ≥ 3. Find limx→3− q(x).

2For the same q, the left limit at 3 is 5, the right limit is 7, and q(3) = 7. Does limx→3 q(x) exist?

D

When substitution gives 0 over 0

A new skill, restated in full

If substituting a gives 0 ÷ 0, the quotient law does not apply, and the expression needs simplifying. There are two standard moves. Factor and cancel: if the top and the bottom share a factor x − a, cancel it. This is allowed in a limit because x approaches a but never equals a, so that factor is not 0. Rationalize: if a square root sits in the top, multiply the top and the bottom by its conjugate (the same two terms with the sign between them flipped). The top becomes a plain expression, and a factor can then cancel. After simplifying, substitute.

ExampleEvaluate limx→2 x2 − 5x + 6x − 2.
  1. Substituting 2 gives (4 − 10 + 6) ÷ 0 = 0 ÷ 0.
  2. Factor the top: x2 − 5x + 6 = (x − 2)(x − 3).
  3. Cancel x − 2. Near 2, but not at 2, the expression equals x − 3.
  4. Substitute: 2 − 3 = −1.
ExampleEvaluate limx→0 √x + 4 − 2x.
  1. Substituting 0 gives (2 − 2) ÷ 0 = 0 ÷ 0. There is a root in the top, so rationalize.
  2. Multiply the top and the bottom by the conjugate, √x + 4 + 2.
  3. The top becomes (x + 4) − 4 = x. The bottom is x(√x + 4 + 2).
  4. Cancel x. This leaves 1√x + 4 + 2.
  5. Substitute 0: 12 + 2 = 14. The laws that allow it are the sum, root, and quotient laws, and the bottom’s limit is 4, not 0.

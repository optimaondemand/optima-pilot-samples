What a Limit Is

Focus

A function can have no value at a point and still head toward one. What does it head toward as x draws near?

Objectives
  • Explain what limx→a f(x) = L means in words and in notation.
  • Estimate a limit from a table of values computed on both sides of the point.
  • Estimate a limit from a graph, and explain why a limit can exist where the function is undefined.
  • Recognize when the two sides head to different values, so the limit does not exist.

A bit of historyNewton and Leibniz built working calculus in the 1600s on an idea of the “infinitely small” that no one could quite define. Critics called it reasoning with ghosts. It took nearly two centuries, and the careful work of Cauchy and Weierstrass in the 1800s, to replace the ghost with the precise idea of a limit. Useful mathematics sometimes runs ahead of its own foundations, and is set right later.
All the words in this lesson
LimitThe value a function’s outputs draw near as the input approaches a point. We write limx→a f(x) = L and read it “the limit of f(x), as x approaches a, equals L.”
ApproachesThe arrow → in limit notation. The input gets as close as we like to the point without having to equal it.
UndefinedA function has no value at an input, such as f(2) when the denominator is zero. The limit can still exist there.
Open circleA small hollow dot on a graph that marks a point the graph does not include.
Table of valuesA list of inputs chosen to march toward a point from the left and from the right, with the output for each.
Does not existWhen the outputs from the left and the outputs from the right head to different values, no single number works, so the two-sided limit does not exist.

limx→2 x2 − 4x − 2 = 4
x2 − 4x − 2 = (x − 2)(x + 2)x − 2 = x + 2for every x ≠ 2
x + 2 would be 4 at x = 2, but f(2) is undefined.
A limit of 4 does not mean f(2) = 4.
ExampleEstimate limx→2 x2 − 4x − 2 from a table.
  1. Choose x-values that march toward 2 from below and from above. Never use x = 2 itself.
  2. From the left, x = 1.9, 1.99, 1.999, 1.9999 give f(x) = 3.9, 3.99, 3.999, 3.9999. The outputs climb toward 4.
  3. From the right, x = 2.1, 2.01, 2.001, 2.0001 give f(x) = 4.1, 4.01, 4.001, 4.0001. The outputs fall toward 4.
  4. Both sides press in on the same number, so limx→2 f(x) = 4, even though f(2) is undefined.
  5. Why it is so clean: for x ≠ 2, (x − 2)(x + 2)x − 2 = x + 2, and x + 2 would be 4 at x = 2.

The Distributive Property on Algebraic Expressions

Focus

How can you multiply a number by a sum and still get an expression with the same value?

Objectives
  • Explain what the distributive property is and how it is used in algebra.
  • Distribute an integer across an algebraic expression, keeping every sign right.
  • Use the distributive property to write equivalent expressions.
  • Decide whether two expressions are equivalent.

Vocab
Algebraic expressionA math phrase with variables, numbers, and operation symbols (+, −, ×, ÷). It has no equal sign. Example: 3x + 4.
CoefficientA number that multiplies a variable. In 4x, 4 is the coefficient of x.
Distributive propertyMultiply a sum by multiplying each addend separately, then add the products: a(b + c) = ab + ac.
Equivalent expressionExpressions with the same value for any values of their variables. 2(x + 3) and 2x + 6 are equivalent.
IntegerA whole number that can be positive, negative, or zero. Examples: −3, 0, 1, 5.
Like termsTerms with the same variable raised to the same power. They can be combined by adding or subtracting their coefficients. In 3x + 4x, both terms have the variable x.
VariableA symbol, usually a letter, for an unknown or changing number. In 7x + 4, x is the variable.

Example 2Use the distributive property to write an equivalent expression for −2(y + 7).
  1. Multiply −2 by both terms: −2 · y = −2y and −2 · 7 = −14.
  2. Write the new expression with the signs of the products. Since one term is −14, it is written with a minus sign: −2y − 14
  3. Remember the rules for multiplying integers. A negative times a positive is negative.
Example 3Use the distributive property to write an equivalent expression for −3(6x − 8).
  1. Multiply −3 by both terms. The minus sign in front of 8 is a negative on the 8, so the second term is −8.
  2. −3 · 6x = −18x and −3 · (−8) = 24.
  3. Write the new expression: −18x + 24
  4. Notice the middle sign changed from minus to plus. A negative times a negative is positive, so the second product is +24.
Example 4Are the expressions 4x + 8 and 4(x + 2) equivalent?
  1. Look for a common factor in 4x + 8. Both terms have a common factor of 4.
  2. Undistribute the 4. Distributing is multiplication, so undoing it uses division: 4x ÷ 4 = x and 8 ÷ 4 = 2.
  3. That gives 4(x + 2), the other expression. Yes, they are equivalent.
Example 5Are the expressions 15x + 28 and 3(5x + 7) equivalent?
  1. Look for a common factor in 15x + 28. 15 = 3 · 5 and 28 = 4 · 7. The two terms have no common factor, so 3 cannot be factored out of 15x + 28.
  2. So 15x + 28 cannot be written as 3 times a sum. No, they are NOT equivalent.
  3. Check by distributing the 3: 3 · 5x = 15x and 3 · 7 = 21, so 3(5x + 7) is 15x + 21, not 15x + 28.

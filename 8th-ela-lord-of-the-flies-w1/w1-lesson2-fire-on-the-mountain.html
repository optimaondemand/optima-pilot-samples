Jonah · 8th Grade Scholar
Plan model

1. Conch scene: Ralph’s first blast. “A deep, harsh note boomed under the palms” (Ch. 1). Boomed is a big, deep word for a shell, so the shell seems to have power over the whole island.

2. Assembly: Ralph left holding the conch. “Ralph was left, holding the conch, with no one but Piggy” (Ch. 2). Left shows everyone else has run off, so the shell is still in his hands but no longer works.

3. Claim: The order looks fragile, because it works only while the boys are listening.

What you make
 
Turn your finished feature into a one-page website using Claude Code. The page presents your words. It does not change them.
Your page includes
 
1Your headline, byline, and standfirst.
2The section headings from your feature.
3A pull-quote taken from your own text.
4At least one supporting visual: a public-domain image with a caption, or a simple original graphic. A caption gives the subject, the origin, the date, and the rights.
5Your source list.
Worth knowing: Claude Code is used differently here
 
Building a web page is a coding task, so in this item Claude Code may write the HTML and CSS. The words are not part of that job. Paste your finished feature in exactly as you submitted it, and take the headline, standfirst, and pull-quote from your own sentences. A code tool can reword text without being asked, so ask it for design and code changes only, then compare the page with your feature. The argument should read as identical. Only the presentation is new. Note in your AI-use line what you asked it to build.
Steps
 
1Open Claude Code in your Optima → ELA → ELA11 folder. Describe a single self-contained HTML page with the parts listed above.
2Paste your feature into the page word for word. Preview the page. Ask for design and code changes only, never for changes to the text.
3Reread the page against your feature. Confirm every sentence is unchanged, and that the headline, standfirst, and pull-quote are your own words.
4Save the page as LastName_FirstName_ChronicleOnline_ELA11.html and submit it here. If you published it, submit the working link instead or as well.
